# Employee Attrition Prediction

## 📌 Project Overview

This is a Machine Learning minor project that predicts whether an employee is likely to leave the company or stay.

## 🎯 Objective

The main objective of this project is to predict employee attrition using employee-related information.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔄 Project Workflow

1. Load the dataset
2. Understand the data
3. Perform data preprocessing
4. Perform Exploratory Data Analysis
5. Prepare data for Machine Learning
6. Split data into training and testing sets
7. Train Machine Learning models
8. Evaluate model performance
9. Predict employee attrition

## 🤖 Machine Learning Models

The project uses the following classification algorithms:

- Logistic Regression
- Decision Tree
- Random Forest

## 📊 Dataset

The dataset contains employee-related information and an Attrition column.

- Yes = Employee may leave
- No = Employee may stay

## 📂 Project Files

- Employee_Attrition_Prediction.ipynb - Main Jupyter Notebook
- Employee_Attrition_Dataset.csv - Dataset
- requirements.txt - Required Python libraries
- README.md - Project documentation
